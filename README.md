# 视频播放助手 1.1.1（安卓独立版）

安卓原生视频播放辅助工具，支持手机独立启动、播放器重试、视频结束后翻页，以及可选的 DeepSeek 视频中途文字单选弹题处理。使用 Java 和 Android 系统 API，无第三方运行时依赖。采用 [MIT 许可证](LICENSE)。

项目结构：`src/` 为应用源码，`res/` 为安卓资源，`test/` 为界面决策和模型响应校验，`build.ps1` 为 Windows 构建入口。可安装的 APK 通过仓库 Releases 提供，仓库不包含签名私钥或 API Key。

安装 `video-helper.apk` 后，可以在手机上开始、暂停和停止辅助。运行时无需电脑、ADB、无线调试、热点或 USB 连接。课程视频和 DeepSeek API 仍然需要网络。

## 手机上开始使用

1. 打开「视频播放助手」。首次安装时，在「启用无障碍服务」里开启「学习通视频辅助」。Android 的开启确认需要本人操作。
2. 返回助手，点击「开始辅助」，再切换到学习通课程的视频页面。显示「服务已就绪」仅表示服务已开启，仍需点击开始。
3. 保持学习通在前台、手机解锁。当前课程要求前台观看；锁屏、最小化或切换应用后，助手会等待返回。
4. 可在助手主页或通知栏暂停、停止。暂停辅助只停止自动点击，不会直接暂停学习通的播放器。

系统服务页面有两个不同开关：顶部「学习通视频辅助」是服务总开关，下方「快捷启用」只是显示快捷按钮。只有快捷按钮开启而顶部关闭时，助手不能操作。点击屏幕右侧的绿色系统快捷按钮可能切换服务的开关；日常开始、暂停请使用助手主页或通知中的按钮。

## 视频中途弹题与 DeepSeek

1. 在助手主页向下滚动，点击「DeepSeek · 视频弹题设置」。
2. 填入自己在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建的 API Key。无需将 Key 发到聊天中；官网登录、会员或聊天账号不等于已经配置了 API Key。
3. 选择模型，默认使用 `deepseek-flash`。勾选「自动选择并提交视频中途弹题」，保存。
4. 点击「开始辅助」，再返回视频。设置改变后会暂停自动操作，需手动重新开始。

目前支持学习通播放器专用弹题窗口里的**文字单选题**。先从无障碍页面中读取题干和全部选项，调用 DeepSeek，再根据当前页面的位置选择并提交。返回时会再次核对题目和选项，避免将旧答案提交到另一道题。章节作业、章节测验、考试不会被当作视频弹题处理。

多选、判断、填空、图片、音频、结构不明或内容不完整的题目会停下来等待本人处理。需要依赖未提供的视频内容时会要求模型拒绝猜测；模型也可能错误地认为自己有把握，不能保证答对。

每次开始最多请求 20 道弹题，同一道题不会自动重发请求。网络失败、超时、无余额、无效 Key、无效选项、模型无法确定、提交后弹题仍未关闭时会停止，原因显示在助手状态、最近操作和通知中。处理完异常后可以重新开始。

## 数据与密钥

- 启用 AI 后，手机直接向 `https://api.deepseek.com/chat/completions` 发送题干、题型和选项，费用由个人 API 账户承担。
- 不向 DeepSeek 发送截图、人脸画面、课程账号、登录 Cookie 或整页内容。普通播放、重试和翻页不调用模型。
- Key 使用 Android Keystore 中不可导出的 AES 密钥加密，保存在此应用的私有目录。设置页不回显已保存的 Key，且禁止该窗口截图。可在设置中清除 Key。
- APK 未内置 API Key，未设置转发服务器。应用关闭备份和明文 HTTP，不跟随 API 重定向。

## 其他功能和限制

- 使用学习通播放器提供的倍速选项。实机提示「该视频教师已关闭倍速功能，任务点完成后可倍速播放」；此课程未完成任务的视频仍按原速播放。
- 播放失败时可自动点击当前视频的重试按钮，连续最多三次。
- 可以确认用户已授权的已知课程监控提示。真正的人脸采集、身份验证和重新登录会停止等待本人操作。
- 观察到视频播放结束后，可以返回章节页、滚动并进入下一节；不改写学习记录，不伪造完成状态。
- 一次开始最多运行六小时。Android 系统回收应用、关闭服务或重启手机后，可能需要重新打开并开始；无法保证所有机型都长期存活。
- 测试手机为 OPPO PLE110 / Android 16。其他学习通版本或页面布局可能需要适配。

## 构建与验证

项目无第三方运行时依赖。构建需要 Windows PowerShell、PATH 中的 JDK 17（`java`、`javac`、`jar`、`keytool`），以及 Android SDK platform 35 和 build-tools 35.0.0。安装 SDK 时选择 `platforms;android-35` 与 `build-tools;35.0.0`，可选安装 `platform-tools` 用于 ADB 实机检查：

```powershell
.\build.ps1 -SdkRoot '你的 Android SDK 路径'
```

也可以设置 `ANDROID_HOME`（或 `ANDROID_SDK_ROOT`）后运行 `.\build.ps1`。构建结果为根目录 `video-helper.apk`；中间文件和本机构建密钥保存在被 Git 忽略的 `build/` 目录。

脚本构建 APK、运行界面决策测试并验证 APK 签名。当前构建使用本机生成的开发签名，不适合作为应用商店正式签名方案。仓库不包含签名私钥；重新生成的签名不能直接覆盖已安装的另一签名版本。请自行保留自己的构建密钥用于后续更新。

当前验证：38 项界面决策检查；11 项在 Android 实际 `org.json` 环境中的响应解析检查。已在 OPPO PLE110 / Android 16 上验证启动、暂停、缺少 Key 时停止，以及真实 DeepSeek 请求、单选弹题选择与提交、弹窗关闭和视频继续播放。短暂断开 ADB 后，手机服务仍继续运行。这些验证不保证所有课程版本、其他题型或答案都适用。

1.1.1 修复：此视频弹题的网页提交控件可能报告无障碍点击成功，但实际未触发提交。现使用按当前按钮位置派发的屏幕触摸手势；若提交后弹窗不关闭，仍会停止，避免重复提交和调用 API。

`.\check-android.ps1 -SdkRoot 'SDK 路径' -Adb 'adb.exe 路径' -Device 'ADB 设备号'` 可在连接的 Android 上运行响应解析测试；这些测试不请求 API，不收费，也不更改学习通中的答案。

API 实现参考 [DeepSeek 首次调用](https://api-docs.deepseek.com/zh-cn/) 和 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。
